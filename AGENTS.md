# Agent guidance

For php-forge/diff integration use the package-owned [skill](skills/php-forge-diff/SKILL.md), the
[usage examples](docs/examples.md), [algorithms guide](docs/algorithms.md), and source at the installed revision. The
[AI assistance guide](docs/agents.md) explains discovery and installation. The package requires PHP 8.3 or later.

For repository changes inspect the Git status and diffs, preserve existing staged and unstaged work, and follow
[testing](docs/testing.md). Do not confuse installation or reading a skill with native activation or a passing task.
